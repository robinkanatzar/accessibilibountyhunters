Accessibilibounty Hunters

It's a bug bounty, but for accessibility bugs. Find them in indie apps, report them, earn points and climb the leaderboard.

Report a bug List your app

How bounty hunting works

  1. Pick an app Choose one of the indie apps listed below and try it with the accessibility features you know: VoiceOver, Voice Control, larger text, keyboard, and so on.
  2. Report what you find Email your bug to hello@robinkanatzar.com. Say what happened, what you expected and how to make it happen again.
  3. Get verified Every report is checked by hand. If something is unclear, you'll get an email asking about it.
  4. Climb the board Verified bugs earn points. The more you find, the higher you go. The top hunter wins a prize of some sort, or at least the glory of being number 1.

What makes a good report

  • The app's name and version, and your device and iOS version.
  • The accessibility feature or setting you were using.
  • The screen you were on and the steps that led to the bug.
  • What happened, and what you expected to happen instead.
  • A screenshot or screen recording, if you can make one.
  • The name you'd like to show on the leaderboard.

  • You get one short, friendly email with the bugs to fix, plus tips and help on how to fix each one. No vague to-do list.

Add a report button to your app

The best bug reports come from people using your app every day. Add a "Report an Accessibility Issue" button to your settings screen. It opens an email to Accessibilibounty Hunters, filled in with your app's details and the accessibility settings the person has turned on.

1. Copy the button into your SwiftUI project

Change appName and appStoreLink to match your app.

ReportAccessibilityIssueButton.swift 
import SwiftUI
import UIKit

/// Opens a pre-filled email to report an accessibility bug.
/// Change appName and appStoreLink, then add
/// ReportAccessibilityIssueButton() to your settings screen.
struct ReportAccessibilityIssueButton: View {
    // Change these to match your app
    private let appName = "My Indie App"
    private let appStoreLink = "https://apps.apple.com/app/id0000000000"

    // Reports go to Accessibilibounty Hunters
    private let reportAddress = "hello@robinkanatzar.com"

    @Environment(\.openURL) private var openURL
    @Environment(\.dynamicTypeSize) private var dynamicTypeSize
    @State private var showNoMailAlert = false

    var body: some View {
        Button {
            guard let url = reportURL else { return }
            openURL(url) { opened in
                if !opened { showNoMailAlert = true }
            }
        } label: {
            Label("Report an Accessibility Issue", systemImage: "accessibility")
        }
        .alert("No Mail App Found", isPresented: $showNoMailAlert) {
            Button("Copy Email Address") {
                UIPasteboard.general.string = reportAddress
            }
            Button("OK", role: .cancel) { }
        } message: {
            Text("Please email your report to \(reportAddress).")
        }
    }

    private var reportURL: URL? {
        let subject = "Accessibility bug: \(appName)"
        return URL(string: "mailto:\(reportAddress)?subject=\(encode(subject))&body=\(encode(emailBody))")
    }

    private var emailBody: String {
        let info = Bundle.main.infoDictionary
        let version = info?["CFBundleShortVersionString"] as? String ?? "unknown"
        let build = info?["CFBundleVersion"] as? String ?? "unknown"
        let device = UIDevice.current

        return """
        What happened?


        What did you expect to happen?


        Steps to reproduce (which screen, what you tapped):


        ---
        Please keep the details below. They help check the bug.
        App: \(appName) \(version) (\(build))
        App Store: \(appStoreLink)
        Device: \(device.model), \(device.systemName) \(device.systemVersion)
        VoiceOver: \(onOff(UIAccessibility.isVoiceOverRunning))
        Switch Control: \(onOff(UIAccessibility.isSwitchControlRunning))
        Text size: \(String(describing: dynamicTypeSize))
        Bold Text: \(onOff(UIAccessibility.isBoldTextEnabled))
        Increase Contrast: \(onOff(UIAccessibility.isDarkerSystemColorsEnabled))
        Reduce Motion: \(onOff(UIAccessibility.isReduceMotionEnabled))
        Reduce Transparency: \(onOff(UIAccessibility.isReduceTransparencyEnabled))
        """
    }

    private func onOff(_ isOn: Bool) -> String {
        isOn ? "On" : "Off"
    }

    private func encode(_ text: String) -> String {
        let unreserved = CharacterSet(charactersIn:
            "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-._~")
        return text.addingPercentEncoding(withAllowedCharacters: unreserved) ?? text
    }
}

2. Add it to your settings screen

SettingsView.swift 
Form {
    Section("Support") {
        ReportAccessibilityIssueButton()
    }
}

Good to know

  • The email lists VoiceOver, Switch Control, text size, Bold Text, Increase Contrast, Reduce Motion and Reduce Transparency. iOS doesn't let apps detect Voice Control or Full Keyboard Access, so people can mention those themselves.
  • If no mail app is set up on the device, the button shows the email address and offers to copy it.
  • Want reports to come to you as well? Add your own address after a comma in reportAddress, or send an email to talk about it.
